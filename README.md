# ⚡ AI-Powered C++ Compiler & Interactive Web IDE

A lightweight 5-stage custom C++ compiler pipeline integrated with an AI-driven diagnostic engine, containerized using Docker, and served via a web-based Monaco IDE interface.

## 🌟 Key Features

- **5-Stage Compiler Engine:**
  1. **Lexical Analysis:** Custom tokenizer mapping tokens, line numbers, and column offsets.
  2. **Parsing & AST Generation:** Recursive descent parser constructing an Abstract Syntax Tree.
  3. **Semantic Analysis:** Symbol table generation and type-checking (detects type mismatches, undeclared variables).
  4. **AI Diagnostics:** Contextual error explanations and code fix suggestions generated by Google Gemini.
  5. **Interpreter:** Statement-by-statement execution engine tracking runtime variable states.

- **Resilient AI Diagnostic Engine (Auto-Fallback):**
  - Sends exact source code error context directly to Google's Gemini API via `libcurl`.
  - Implements an automated **Multi-Model Fallback Pipeline** (`gemini-3.8-flash` $\rightarrow$ `gemini-3.5-flash-lite`) to bypass free-tier rate limits and 503 high-demand traffic spikes seamlessly.

- **Interactive Monaco Web IDE:**
  - Browser-based code editing using the VS Code core engine (Monaco Editor).
  - Real-time compiler output telemetry panel paired with styled AI diagnostic advice cards.

- **Production Ready & Containerized:**
  - Self-contained `Dockerfile` compiling C++ binaries and configuring Python dependencies.
  - Render-ready with dynamic port binding support.

## 🏗 Architecture Overview

```

[ User Input ] (Monaco Editor in Browser)
│
▼  HTTP POST /api/compile
[ FastAPI Backend ] (app.py Orchestrator)
│
▼ Subprocess Invocation
[ C++ Compiler Binary ]
├── 1. Lexer (Token Generation)
├── 2. Parser (AST Construction)
├── 3. Semantic Analyzer (Symbol Table & Type Check)
├── 4. Gemini Diagnostic Client (CURL + Auto-Fallback Pipeline)
└── 5. Interpreter Execution
│
▼ Combined Output JSON
[ Web Telemetry & Formatted AI Advice UI ]

```

## 🚀 Quick Start (Local Development)

### Prerequisites

- GCC / G++ (supporting C++17)
- CMake (>= 3.10)
- `libcurl4-openssl-dev` & `nlohmann-json3-dev`
- Python 3 & `pip`
- A valid `GEMINI_API_KEY` from [Google AI Studio](https://aistudio.google.com)

### 1. Clone & Set Environment Variable

```bash
git clone [https://github.com/Itssonia7/ai-syntax-compiler-cpp.git](https://github.com/Itssonia7/ai-syntax-compiler-cpp.git)
cd ai-syntax-compiler-cpp

export GEMINI_API_KEY="your_google_ai_studio_api_key_here"

```

### 2. Build the C++ Compiler Binary

```bash
mkdir -p build && cd build
cmake ..
make
cd ..

```

### 3. Install Python Dependencies & Launch Web IDE

```bash
pip install fastapi uvicorn pydantic --break-system-packages
python3 app.py

```

Open your browser at **`http://localhost:8000`**.

## 🐳 Running with Docker

Run the entire application in an isolated container without needing local C++ or Python dependencies:

```bash
# Build and run with Docker Compose
GEMINI_API_KEY="your_api_key" docker compose up --build

```

Access the Web IDE at `http://localhost:8000`.

## ☁️ Cloud Deployment (Render)

1. Push your latest code to GitHub.
2. Log into [Render](https://render.com) and create a **New Web Service**.
3. Connect your GitHub repository.
4. Set **Runtime** to `Docker`.
5. Add an Environment Variable:

- **Key:** `GEMINI_API_KEY`
- **Value:** `your_google_ai_studio_key`

6. Deploy! Render will build the container and issue a public URL.
